Study studies/cv_patrol_identity.py (study-only; imports cv_patrol_lateral read-only; mutates no existing parquet; official data validation/reference only). STAGE A LUT: RapidOCR pooled over the finish-cam window vid t=105.5-118.6s reads 7/12 saddlecloth numbers (#1,2,3,6,8,9,12 -- 0077's '11/12' not reproduced at conf>0.6; the cam tracks the leaders, back-markers #4,7,10,11 exit frame). For each OCR'd number the nearest saturated silk blob ABOVE it is sampled -> per-number LAB. PROBLEM: the side-on torso is a motion-blurred sliver and the chroma-weighted median collapses to the dominant red-cap/sleeve fragment, so #3(navy+red),#8(yellow/black),#12(grey+purple),#9(red),#6(blue) ALL read as variants of dark red (RGB ~ (130,60,75)) -- not separable. STAGE B head-on track silks (re-detect via _silk_mask, LAB median over the jockey silk bbox per detection) have the SAME collapse: 12/12 robust tracks but signatures span only LAB a 162-182 (all red-magenta). The Hungarian then assigns 7 tracks to the 7 LUT numbers; only 6/12 clear the conf>=0.35 margin gate; stewards agreement 3/4 (#12,#8 TIGHT OK, #2 MID-ok, #6 MISS) with a near-zero +0.3m wide-rail gap. The lateral GEOMETRY is fine (0076's validated fan, tracks span off 4.7-14.9m); the identity COLOUR read is the weak link. FIX in progress: per-jockey dominant-hue extraction (HSV hue histogram mode over the silk core, excluding the near-universal red sleeve band) for both LUT and head-on, then re-match.
